- **Agentic AI:** LangGraph + RAG over clinical guidelines
- **Stack:** Kafka → Spark → Delta Lake → MLflow → FastAPI → AWS ECS

> Connects surrendered medications with patients who can't afford them
- **AI:** Groq API (Llama 4 Scout vision model) for automated medication intake
- **Features:** Role-based dashboards, geolocation matching, controlled substance flagging, expiration monitoring
- **Stack:** Next.js · React · Node.js · Twilio · Resend
